# 디스코드 비서 사용법

비서는 이 문서를 읽고 사용법 질문에 답해요. 디스코드에서 "○○ 어떻게 써?"라고 묻거나 `!help 주제`(예: `!help 쿠폰`)로 바로 볼 수 있어요.
기능을 추가·변경하면 이 문서도 같이 고쳐요. 설치와 키 설정은 `docs/setup-guide.md`에 있어요.

## 기본: 대화하는 곳과 방법
키워드: 시작, 기본, 채널, 멘션, 호출, DM, 홈 채널, 답이 없어, 초기화, 깊게
- 홈 채널과 봇 DM에서는 그냥 말하면 돼요. 다른 채널에서는 `@Claude비서`로 불러야 답해요. 본인 메시지에만 반응해요.
- 홈 채널의 스레드와 프로젝트 스레드에서도 멘션 없이 대화해요.
- 버튼이 붙은 "확인 필요" 메시지는 [실행]을 눌러야 실제로 처리돼요 (일정 추가, 카톡 보내기, 이슈 만들기 등).
- `!reset` 대화 기록 지우기 · `!deep 질문` 깊게 생각하기(더 비싼 모델) · `!help` 도움말 · `!help 주제` 이 문서에서 찾아보기
- 답이 없으면: 홈 채널 ID(`.env`의 `DISCORD_HOME_CHANNEL_ID`)와 봇의 채널 권한(보기·보내기·메시지 기록 보기)을 확인해요.

## 메일
키워드: 메일, 이메일, Gmail, 답장, 초안, 중요 메일, 알림, 야간 요약
- "오늘 온 메일 중 중요한 거 있어?", "○○에서 온 메일 찾아줘" — Gmail은 읽기 전용이에요 (보내기·삭제·읽음 표시 없음).
- 새 메일은 2분마다 확인하고, 중요한 것만 알려요. 긴급 메일은 밤에도 바로, 나머지는 조용한 시간엔 모아둬요.
- 알림에 납부·마감·회의가 있으면 [할 일] [캘린더] 버튼이 붙어요. 누를 때만 등록돼요.
- [✉️ 답장 초안] 버튼 또는 "그 메일 답장 써줘, 화요일 가능하다고" → 초안과 Gmail 새 메일 창 버튼. 정하지 않은 날짜·금액은 [ ] 빈칸으로 남겨요.
- 매일 21:07에 그날 메일을 배치로 요약해요.
- 설정: `config.yaml`의 `mail` (VIP·무시할 발신자, 알림 기준).

## 일정 (구글 캘린더)
키워드: 일정, 캘린더, 약속, 스케줄, 톡캘린더, 카카오 캘린더
- "내일 일정 알려줘", "금요일 3시에 치과 일정 넣어줘" → 추가는 [실행] 확인 후.
- 카톡에서 만든 일정(톡캘린더)도 읽어서 일정 조회·아침 브리핑(💬 표시)·출발 알림에 포함해요 (`talkcal.read`, 톡캘린더 연동이 켜져 있을 때).
- 톡캘린더: 구글 캘린더 2주치를 카카오 톡캘린더에도 넣어 카톡 알림으로 받아요. `config.yaml`의 `talkcal.enabled: true`와 카카오 재로그인(`deploy/kakao_auth.py`)이 필요해요. 권한 오류로 멈추면 `!talkcal on`.

## 리마인더와 할 일 (갤럭시 리마인더)
키워드: 리마인더, 할 일, 알람, 투두, To Do, 갤럭시, 삼성 리마인더, 완료, 쪼개기, 계획
- "30분 뒤에 빨래 알려줘", "매주 월요일 9시 주간회의 준비" → Microsoft To Do에 들어가고 갤럭시 삼성 리마인더로 동기화돼 폰 알람이 울려요.
- "할 일 뭐 있어?" → 폰에서 만든 것까지 번호 목록. "우유 샀어" / "3번 완료" → 완료 처리(폰에서도 완료).
- 동기화에 몇 분 걸려서 아주 가까운 알림은 늦을 수 있어요. 디스코드로도 받으려면 `todo.discord_too: true`.
- 큰 일 쪼개기: "FA 0.2 출시 준비 다음 달 15일까지 쪼개줘" → 단계·날짜 계획을 보여주고 [실행]을 누르면 한 번에 등록해요. 마감을 안 말하면 먼저 물어봐요.

## 출발 알림
키워드: 출발, 이동, 길찾기, 내비, 대중교통, 자동차, 집, 회사, 출발지, 카카오내비
- 구글 캘린더 일정에 **장소**가 있으면 출발 15분 전에 대중교통·자동차 시간, 출발 시각, 도착지 비 소식을 알려요.
- 처음 한 번: `!place 집 주소`, `!place 회사 주소`. `!place`만 치면 등록된 곳을 보여줘요.
- 출발지는 평일 09~18시 회사, 그 외 집. 오늘만 바꾸기: `!origin 회사`, `!origin 서면역`, `!origin`(초기화).
- 알림 카드 버튼: [🏠 집에서] [🏢 회사에서] 다시 계산 · [🚗 카카오내비] · [🚌 카카오맵 길찾기].
- 온라인 회의·종일 일정·400m 안쪽은 알리지 않아요. 카카오 콘솔에서 카카오맵 API 활성화가 필요해요.
- 설정: `config.yaml`의 `commute` (여유 시간, 근무 시간, 이동 수단).

## 약속 카드와 중간 지점
키워드: 약속 카드, 공유, 카톡 공유, 카카오톡 공유, 중간 지점, 만날 곳, 모임
- "토요일 7시 서면 ○○ 약속 카드 만들어줘" → 지도·내비·길찾기·[카카오톡으로 공유] 버튼이 있는 페이지 링크. 공유 대상은 본인이 골라요.
- "해운대, 사상, 동래에서 만나기 좋은 곳 찾아줘, 고깃집" → 대중교통 시간이 가장 고른 지하철역, 근처 가게, 공유 카드.
- 답변에 카드 링크가 있으면 [💬 내 카톡으로 보내기] 버튼이 붙어요. 누르면 나와의 채팅으로 카드가 오고, 카톡에서 그 메시지를 길게 눌러 **전달**하면 페이지를 열지 않고 친구에게 보낼 수 있어요.
- 봇이 친구에게 직접 보내는 건 카카오 정책상 안 돼요 (나에게 보내기만 가능).
- 카드 내용은 링크 안에만 있고 사이트에는 저장되지 않아요. GitHub Pages와 `KAKAO_JS_KEY` 설정이 필요해요.

## 스크린샷 비서
키워드: 스크린샷, 사진, 캡처, 영수증, 예매, 청첩장, 이미지
- 사진을 **글 없이** 보내면 종류를 알아보고 카드와 버튼을 띄워요. 힌트를 주려면 `!snap 이거 영수증이야`와 함께.
- 일정 → 캘린더 · 할 일 → To Do · 기프티콘 → 지갑 저장 + 만료 3일 전 알림 · 택배 → 할 일 · 영수증 → Notion 지출 · 그 외 → Notion 메모.
- 버튼은 여러 개 눌러도 돼요. 한 번에 4장, 장당 5MB까지. 사진에 글을 같이 쓰면 일반 대화로 처리돼요.

## 기프티콘 지갑
키워드: 기프티콘, 쿠폰, 지갑, 바코드, 선물, 만료
- 기프티콘 스크린샷을 보내면 원본 이미지와 함께 자동 저장돼요.
- `!coupons` 목록(만료 임박 순) · "스벅 쿠폰 보여줘" → 바코드 원본 이미지 · "스벅 쿠폰 썼어" → 사용 처리.
- "스벅 쿠폰 넘길 카드 만들어줘" → [실행] 후 공유 카드 링크. 링크를 가진 사람은 쿠폰 번호를 볼 수 있어요.

## 지출
키워드: 지출, 가계부, 돈, 영수증, 예산, 리포트, 식비, 시트, 엑셀
- 영수증 스크린샷의 [지출 기록] 버튼으로 Notion "지출" DB에 쌓여요.
- 글로도 기록해요: "점심 9천원 썼어", "어제 택시 12,000원 카드로" → 분류를 골라 바로 기록하고 한 줄로 알려줘요. "방금 거 취소"로 지워요.
- 카드 결제는 문자로 자동 기록할 수 있어요 → "결제 문자 자동 기록" 참고.
- 빠른 명령(무료): `!spend 9000 점심 식비` (분류 생략 시 기타) · `!spend undo` 방금 기록 지우기.
- `!spend` 이번 달 · "이번 달 식비 얼마야?" · 월요일 08:47 지난주 리포트 · 매월 1일 지난달 리포트.
- 구글 시트: 매일 04:37에 Notion 지출을 구글 시트 "지출 (비서)"로 옮겨요(내역 탭 + 분류별 월 합계 탭). `!sheet`로 지금 동기화하고 링크를 받아요. Notion이 원본이라 시트에서 고친 내용은 덮어써져요.
- 분류별 예산: `config.yaml`의 `expenses.budgets: {식비: 400000}` → 80%·100%에서 알림.

## 결제 문자 자동 기록
키워드: 결제 문자, 카드 문자, 삼성페이, 자동 기록, 승인 문자, 전달 앱, APK, 웹후크, 카드 결제
- 카드사 승인 문자가 오면 폰의 전달 앱이 전용 디스코드 채널로 보내고, 비서가 금액·가맹점을 읽어 Notion "지출"에 바로 기록해요. 삼성페이·온라인·실물 카드 결제가 모두 잡혀요.
- 기록 카드의 **분류 바꾸기**로 분류를 고치면 그 가맹점은 다음부터 그 분류로 기록해요. **기록 지우기**로 지워요.
- 같은 금액이 10분 안에 또 오면 기록하지 않고 [기록] / [무시]를 물어요. 취소 문자가 오면 같은 금액의 최근 기록을 찾아 지워요.
- 결제예정 금액·광고·인증번호 문자는 무시하고 👀 표시만 남겨요 (비서가 받긴 했다는 뜻). 해외 결제(원화 금액이 없는 문자)는 아직 기록하지 않아요.
- `!pay` 상태와 이번 달 건수 · `!pay test 문자 내용` 기록하지 않고 어떻게 읽는지만 확인.
- 켜는 순서:
  1. 디스코드에 전용 채널(예: #결제)을 만들고, 채널 편집 → 연동 → 웹후크 → 새 웹후크 → **웹후크 URL 복사**. 비서가 그 채널을 보고 글을 쓸 수 있어야 해요.
  2. 웹후크 URL은 `https://discord.com/api/webhooks/숫자/토큰` 모양이에요. **숫자** 부분이 웹후크 ID예요. 토큰은 비서에 알려주지 않아요.
  3. 홈 채널에서 `!set paysms.channel_id 채널ID` · `!set paysms.webhook_id 웹후크ID` · `!set paysms.enabled true` → `!restart`. 채널 ID는 디스코드 설정 → 고급 → 개발자 모드를 켠 뒤 채널을 길게 눌러 "ID 복사"로 얻어요.
  4. 폰에 **결제 문자 전달** 앱을 설치해요. 저장소 Releases의 `paysms-app`에서 번호가 가장 큰 APK를 PC로 받아요. 폰에서 바로 설치하면 Play 프로텍트가 막으니 PC에서 USB(adb)로 설치하고, 설치 뒤에는 USB 디버깅을 다시 꺼요. 자세한 순서는 `docs/setup-guide.md` 13단계 "전달 앱 설치"에 있어요.
  5. 앱을 열고 화면 순서대로: ① 알림 접근 권한 허용 → ② 배터리 "제한 없음" → ③ 웹후크 URL 붙여넣고 저장 → ④ 테스트 보내기.
  6. "결제 문자 예시로 테스트"를 누르면 #결제 채널에 예시 문자가 올라오고 비서가 1,000원 기록 카드를 붙여요. [기록 지우기]로 지워요.
- 앱은 메시지 앱(삼성 메시지·구글 메시지)의 알림만 읽고, 카드사 이름 + 승인/취소 + 금액이 모두 있는 문자만 보내요. 다른 문자는 폰 밖으로 나가지 않아요.
- 통신이 끊겨 못 보낸 문자는 앱이 보관했다가 다시 보내요(3일까지).
- 앱을 새 버전으로 바꿀 때는 기존 앱을 지우고 설치해요(서명 키가 빌드마다 달라요). 지우면 웹후크 주소를 다시 넣어야 해요.
- 앱 코드는 저장소 `android/` 폴더에 있고, 고치면 GitHub Actions(`android` 워크플로)가 APK를 다시 만들어요.
- 웹후크 URL은 폰의 전달 앱에만 넣어요. 새어 나가면 그 채널에 가짜 지출이 기록될 수 있으니 디스코드에서 웹후크를 지우고 새로 만들어요.

## 나중에 읽기
키워드: 링크, 기사, 유튜브, 요약, 읽을거리, 북마크, 책, 독서
- **링크만** 보내면 요약해서 Notion "나중에 읽기"에 저장해요. 유튜브는 자막이 막히면 제목·설명으로만 요약해요.
- "나중에 읽기 목록" · "○○ 읽었어" → 읽음 처리 · 토요일 09:47 안 읽은 목록.
- 링크에 글을 같이 쓰면 저장하지 않고 일반 대화로 처리돼요.
- 책: "○○ 읽기 시작했어", "○○ 다 읽었어", "○○ 읽고 싶어" → 책 정보를 찾아 Notion "독서"에 기록해요 (저자·출판사·표지 자동).

## 서재 (문서 질문)
키워드: 서재, PDF, 문서, 파일, 표준, 인용, 쪽 번호
- PDF나 긴 텍스트 파일을 올리면 서재에 저장돼요. "S-52에서 DEPCNT 조건이 뭐야?" → 쪽 번호·인용과 함께 답해요.
- `!docs` 목록 · `!docdel 번호` 삭제 · `!docclean` 안 쓰는 업로드 파일 정리.
- 회사 내부 문서, 민감한 개인 문서, 암호 걸린 PDF는 올리지 마세요. 스캔본(글자 없는 PDF)은 정확도가 떨어져요.

## 개발 (GitHub·Notion)
키워드: 깃허브, 커밋, 이슈, 워크플로, 개발 일지, 노션, 메모, 프로젝트, 스레드
- "내 게임 저장소 어제 뭐 바꿨지?", "my-app 이슈 만들어줘"([실행] 확인), "개발 일지 돌려줘".
- "이거 노션에 메모해줘" → Notion "비서 메모" 아래에 페이지 생성.
- 프로젝트 스레드: 홈 채널에서 `!project my-app` → 📁 스레드. 그 안에서는 그 저장소·최근 커밋 기준으로 대화해요. `!project` 확인, `!project off` 해제.
- 대량 작업: "지난주 커밋 각각 한 줄로 요약해서 배치로 돌려줘" → 50% 할인 배치, 끝나면 결과가 와요.

## 생활 (날씨·장소·부산 실시간)
키워드: 날씨, 맛집, 후기, 블로그, 장소, 버스, 정류소, 특보, 나가도 돼, 미세먼지, 파도, 카톡 보내기
- "서면 ○○국밥 어때?", "해운대 카페 추천해줘" → 카카오 장소 검색 + 다음 블로그·카페 후기를 확인해 장단점과 후기 링크를 줘요 (무료 검색).
- "오늘 날씨", "서면 근처 국밥집", "이거 카톡으로 나한테 보내줘"([실행] 확인).
- `!out` 또는 "지금 나가도 돼?" → 날씨·3시간 내 비·바람·파도·부산 특보·즐겨찾는 정류소 버스 도착.
- `!bus add 서면역`(여러 곳이면 정류소번호로 다시) · `!bus` · `!bus del 이름`. 새 특보는 밤에도 바로 알려요.
- 버스와 특보는 `.env`의 `DATA_GO_KR_KEY`가 필요해요. 날씨·파도는 키 없이 돼요.

## 생활 주기
키워드: 주기, 필터, 칫솔, 교체, 점검, 엔진오일
- `!cycle add 정수기필터 90 [마지막날짜]` 또는 "칫솔 3달마다 알려줘". `!cycle` 목록, `!cycle del 이름`.
- 때가 되면 알리고, 했으면 `!done 정수기필터` → 다음 주기가 오늘부터 다시 시작돼요.

## 생일과 유튜브
키워드: 생일, 기념일, 연락처, 주소록, 유튜브, 구독, 새 영상, 채널
- 생일: 구글 주소록의 생일·기념일을 읽어 당일 08:07에 알려요. `!birthdays` 60일 안의 목록, "다음 달 생일 누구 있어?"도 돼요.
- 유튜브: 매일 19:00에 구독 채널의 새 영상을 한 줄 요약과 함께 묶어 보내요(쇼츠 제외, 최대 25개). `!yt`로 지금 확인.
- 마음에 드는 영상은 링크만 다시 보내면 "나중에 읽기"에 저장돼요.
- 구글 재로그인으로 권한을 추가해요: 연락처는 `deploy/google_auth.py`, 유튜브는 따로 `deploy/google_auth.py --youtube` (구글이 유튜브 권한을 다른 권한과 함께 요청하지 못하게 해요). Cloud 콘솔에서 People API·YouTube Data API v3·Google Sheets API를 켜야 해요.
- 설정: `config.yaml`의 `birthdays`, `youtube`, `expense_sheet`.

## 기억과 검색
키워드: 기억, 지난번, 언제, 어디였지, 검색, 메모리
- "지난달 그 국밥집 어디였지?", "치과 마지막으로 언제 갔지?" → 지난 대화(1년 보관)·지난 일정·지출·Notion을 한 번에 찾아요.
- "내 이름은 ○○야, 기억해" → 오래 기억할 내용 저장. `!memory`로 확인.

## 알림 시간표
키워드: 알림, 브리핑, 조용한 시간, 방해 금지, 묶음, 회고, 시간, 언제 와
- 언제든 바로: 출발 알림, 직접 건 리마인더, 긴급 메일, 부산 특보.
- 23:00~07:00(조용한 시간)과 집중 시간에는 나머지를 모아뒀다가 아침 브리핑·12:30·18:30에 한 번에 보내요. `!queue` 개수, `!flush` 지금 받기.
- 07:47 아침 브리핑(날씨·미세먼지·일정·첫 출발·할 일·교체 주기·만료 쿠폰·밤사이 알림·오늘 동선 지도)
- 04:37 지출 시트 동기화 · 08:07 생일 · 09:07 토큰 점검·재발급 알림 · 19:00 유튜브 새 영상 · 21:07 메일 요약 · 월 08:47 주간 지출 · 매월 1일 08:52 월간 지출 · 토 09:47 안 읽은 글
- 일 21:07 나의 한 주(`!week`로 지금) · 일 22:37 자기 개선 · 일 04:17 백업
- 시각은 `config.yaml`의 `alerts`, `briefing`, `expenses`, `readlater`, `weekly_review`, `backup`에서 바꿔요.

## 대시보드
키워드: 대시보드, 한눈에, 홈 화면, 페이지
- `!dash` → 일정·할 일·지출·쿠폰·주기·비용을 보여주는 개인 페이지 링크. 폰 홈 화면에 추가해 두면 편해요.
- 링크가 열쇠예요. 다른 사람에게 보내지 마세요. `!dash reset`으로 열쇠를 바꾸면 예전 링크는 안 열려요.
- 07~23시에 내용이 바뀌면 매시간 갱신돼요. 비서 GitHub 토큰에 claude-discord-assistant 저장소 Contents 쓰기 권한이 필요해요.

## 비용과 한도
키워드: 비용, 요금, 예산, 토큰, 사용량, 절약 모드, 웹 검색, 한도, 크레딧
- `!budget` 이번 달 비용·월말 예상·웹 검색 횟수 · `!usage` 오늘 토큰 사용량.
- 월 $100 예산: 80%에서 경고, 100%를 넘으면 절약 모드(깊은 모드·어드바이저·플레이테스트·자기 개선 멈춤). `!budget off` 해제, `!budget on` 켜기.
- 웹 검색은 1회 $0.01, 하루 50회까지. GitHub Actions에서 도는 플레이테스트·개발 일지 비용은 포함되지 않아요.

## 설정 바꾸기
키워드: 설정, config, 켜기, 끄기, 시각 바꾸기, 옵션
- 디스코드에서 바로 바꿔요: `!set talkcal.enabled true`, `!set briefing.time "07:30"`, `!set youtube.enabled false`. 그다음 `!restart`.
- `!config` 지금 바꿔 둔 값 보기 · `!unset 경로` 기본값으로 되돌리기.
- 바꾼 값은 VM의 `config.local.yaml`에만 저장돼요. `config.yaml`은 직접 고치지 마세요 (`!update`가 충돌해요).
- 설정 항목 이름은 저장소의 `config.yaml`에 주석과 함께 있어요. 없는 항목이나 형식이 다른 값은 거절해요.
- 비밀값(토큰·키)은 여기가 아니라 VM의 `.env`에 넣어요.

## 관리 명령
키워드: 업데이트, 백업, 복구, 재발급, 토큰, 자기 개선, 플레이테스트, 재시작, 오류, 로그
- `!update` 최신 코드 받고 재시작 · `!backup` 지금 구글 드라이브로 백업 (복구: VM에서 `deploy/restore.py --latest`).
- `!renewals` 재발급 일정 · `!renewed 키` 재발급 기록 · `!renewed 키 YYYY-MM-DD` 새 만료일.
- `!improve` 지난 7일 기록을 분석해 수정안 PR 만들기(대화 10턴 이상) · `!playtest [목표]` AI 플레이테스트(GitHub Actions).
- 봇이 죽으면 healthchecks.io가 디스코드로 알려요(`HEALTHCHECK_URL` 설정 시).
- 문제가 생기면 VM에서 `journalctl -u ai-assistant -n 50 --no-pager`로 로그를 봐요.
- GitHub 404 오류: 비서 토큰이 그 저장소를 못 보는 거예요. Fine-grained 토큰의 Repository access에 저장소를 추가하고 Contents·Pull requests·Actions·Issues를 Read and write로 줘요.
