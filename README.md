# ai-assistant — 디스코드 개인 비서

디스코드에서 말을 걸면 Claude가 메일·일정·할 일·지출·개발·조사·생활 정보를 대신 처리해 주는 개인 비서예요. 무료 클라우드 VM 한 대에서 24시간 돌고, 비용은 Claude API 사용량뿐이에요(기본 월 100달러 상한).

- **누구를 위한 것:** 혼자 쓰는 개인 비서예요. 디스코드 계정 하나(나)에게만 응답해요.
- **어떻게 쓰나:** 디스코드에서 평소 말하듯 쓰면 돼요. 사진·링크·PDF를 보내도 되고, 비서가 먼저 알림·브리핑을 보내기도 해요.
- **무엇이 필요한가:** Oracle Cloud(무료 VM), GitHub, Discord, Anthropic 계정이 필수예요. 나머지(Gmail, 구글, Microsoft, Notion, 카카오, 공공데이터포털, healthchecks.io)는 쓰고 싶은 기능만 연결하면 돼요.
- **설치 방법:** 설치 스크립트(systemd) 또는 Docker(`docker compose up -d`) 중에서 골라요.
- **설치 시간:** 필수 단계는 1시간 안팎, 전체 기능은 반나절 정도예요.

1~5단계만 하면 디스코드에서 대화하는 비서가 켜지고, 6단계부터는 원하는 기능만 골라 붙이면 돼요.

| 단계 | 할 일 | 켜지는 기능 | 필수 |
| --- | --- | --- | --- |

| 5 | VM에 설치하고 처음 켜기 | 대화, 웹 검색, 서재, 기억, 날씨 | 필수 |

## Claude에게 설치·사용법 안내받기

아래 프롬프트를 Claude(claude.ai)에 붙여 넣으면 설치 방법과 사용 방법을 한 단계씩 안내받을 수 있어요. Claude가 저장소를 읽지 못하는 환경이면 `README.md`, `docs/setup-guide.md`, `docs/usage.md` 세 파일을 함께 첨부하세요.

```text
너는 "ai-assistant"(디스코드 개인 비서) 설치와 사용을 도와주는 안내자야.
기준 문서는 README.md, docs/setup-guide.md(설치 가이드), docs/usage.md(사용법)이야.
첨부한 파일이 있으면 그걸 읽고, 없으면 저장소 https://github.com/Ashegyu/claude-discord-assistant 에서 읽어.
문서를 읽을 수 없으면 기억으로 추측하지 말고, 세 파일을 첨부해 달라고 먼저 말해 줘.

진행 방식
1. 시작하기 전에 세 가지를 물어봐.
   - 쓰고 싶은 기능 (1~5단계는 필수, 6~13단계는 Gmail·구글·To Do·Notion·카카오·Pages·공공데이터·결제 문자 중 선택)
   - 내 PC 운영체제 (Windows / macOS / Linux)
   - 내 폰 (안드로이드 / 아이폰)
2. 답에 맞춰 내가 할 단계 목록과 단계마다 걸리는 대략의 시간을 먼저 보여 줘.
3. 한 번에 한 단계만 설명해. 각 단계는 이 순서로:
   ① 이 단계에서 무엇을 왜 하는지 한두 문장
   ② 어느 사이트·화면에서 무엇을 누르는지 번호 순서
   ③ 복사해서 실행할 명령 (어디서 실행하는지: 내 PC / VM / 디스코드)
   ④ 성공하면 보이는 것
   내가 "됐어"라고 하면 다음 단계로 가.
4. 내가 오류 메시지나 화면 내용을 붙이면, 설치 가이드의 문제 해결 표부터 확인해서 원인과 해결 방법을 알려 줘.
5. 설치가 끝나면 사용법 문서를 바탕으로 자주 쓰는 기능 5가지를 골라, 디스코드에서 직접 한 번씩 해 보게 안내해 줘.
6. 이후에는 내가 "○○ 어떻게 써?"라고 물으면 사용법 문서의 해당 부분으로 답해 줘.

지켜 줄 것
- API 키, 토큰, 비밀번호, 웹후크 주소를 채팅에 붙여 넣으라고 하지 마. 값을 넣는 곳(VM의 .env, GitHub Secrets, 폰 앱)만 알려 줘.
  내가 실수로 붙여 넣으면 그 값을 바로 재발급하라고 알려 줘.
- 문서에 없는 메뉴 이름이나 화면은 "문서에 없어서 확인이 필요하다"고 밝혀.
- 유료 전환이나 결제가 필요한 선택지가 나오면 미리 알려 줘. 이 비서는 무료 범위 안에서 설치하는 게 기본이야.
- 한국어로, 짧은 문장으로, 서버를 처음 다뤄 보는 사람도 따라 할 수 있게 설명해.
```

## 기능 상세

각 기능의 "필요한 단계"는 설치 가이드의 단계 번호예요. 1~5단계는 모든 기능에 필요해서 생략했어요.

### 대화 기본

홈 채널과 봇 DM에서는 그냥 말하면 되고, 다른 채널에서는 `@봇이름`으로 불러요. 홈 채널의 스레드에서도 대화할 수 있어요. 바깥에 영향을 주는 일(일정 추가, 카톡 보내기, 이슈 만들기 등)은 **[실행]** 버튼을 눌러야 실제로 처리돼요.

- "내 이름은 ○○야, 기억해" → 오래 기억할 내용으로 저장 (`!memory`로 확인)
- "지난달 그 국밥집 어디였지?" → 지난 대화(1년 보관)·지난 일정·지출·Notion을 한 번에 찾아요
- `!deep 질문` → 더 비싼 모델로 깊게 생각해서 답해요
- `!reset` → 지금 채널의 대화 기록을 지워요

### 메일 (필요한 단계: 6)

Gmail을 2분마다 확인해서 중요한 메일만 바로 알려줘요. 읽기 전용이라 보내기·삭제·읽음 표시를 하지 않아요.

- "오늘 온 메일 중 중요한 거 있어?", "○○에서 온 메일 찾아줘"
- 알림에 납부·마감·회의가 있으면 [할 일] [캘린더] 버튼이 붙어요
- [✉️ 답장 초안] 또는 "그 메일 답장 써줘, 화요일 가능하다고" → 초안과 Gmail 새 메일 창 버튼
- 매일 21:07 하루치 메일 요약

### 일정과 출발 알림 (필요한 단계: 7, 출발 알림은 10)

구글 캘린더를 읽고 일정을 추가해요. 장소가 있는 일정은 출발 15분 전에 대중교통·자동차 이동 시간과 출발 시각, 도착지 비 소식을 알려줘요.

- "내일 일정 알려줘", "금요일 3시에 치과 일정 넣어줘"
- 처음 한 번 `!place 집 주소`, `!place 회사 주소` → 평일 근무 시간엔 회사, 그 외엔 집에서 출발로 계산
- 오늘만 출발지 바꾸기 `!origin 서면역`
- 알림 카드의 [카카오내비] [카카오맵 길찾기] 버튼
- 톡캘린더를 켜면 구글 일정이 카카오 톡캘린더에도 들어가고, 카톡에서 만든 일정도 읽어요

### 할 일과 리마인더 (필요한 단계: 8)

Microsoft To Do와 연동돼서 갤럭시 삼성 리마인더(또는 To Do 앱)로 폰 알람이 울려요. 폰에서 만든 할 일도 비서가 읽고 완료 처리해요.

- "30분 뒤에 빨래 알려줘", "매주 월요일 9시 주간회의 준비"
- "할 일 뭐 있어?" → 번호 목록, "3번 완료"
- "출시 준비 다음 달 15일까지 쪼개줘" → 단계·날짜 계획을 보여주고 [실행]하면 한 번에 등록
- `!cycle add 정수기필터 90` → 교체 주기마다 알림, `!done 정수기필터`로 다시 시작

### 지출 (필요한 단계: 9, 결제 문자는 13, 시트는 7)

Notion "지출" DB에 쌓고, 주간·월간 리포트와 예산 알림을 보내요. 기록하는 방법은 네 가지예요.

| 방법 | 예 |
| --- | --- |
| 말로 | "점심 9천원 썼어", "어제 택시 12,000원 카드로" |
| 명령으로 (모델 안 씀, 무료) | `!spend 9000 점심 식비`, `!spend undo` |
| 영수증 사진 | 사진만 보내면 [지출 기록] 버튼 |
| 카드 결제 문자 (자동) | 결제하면 폰 앱이 문자를 전달 → 바로 기록. 같은 금액 중복·취소 문자도 처리 |

- `!spend` 이번 달, "이번 달 식비 얼마야?"
- 월요일 08:47 지난주 리포트, 매월 1일 지난달 리포트
- 매일 04:37 구글 시트 "지출 (비서)"로 동기화 (`!sheet`)

### 기프티콘과 스크린샷

사진을 글 없이 보내면 종류를 알아보고 맞는 버튼을 띄워요.

| 사진 종류 | 하는 일 |
| --- | --- |
| 일정 (예매, 청첩장 등) | 캘린더에 추가 |
| 할 일, 택배 | To Do에 등록 |
| 기프티콘 | 원본째 지갑에 보관, 만료 3일 전 알림 |
| 영수증 | Notion 지출 기록 |
| 그 외 | Notion 메모 |

- `!coupons` 목록, "스벅 쿠폰 보여줘" → 바코드 원본, "스벅 쿠폰 썼어" → 사용 처리

### 읽을거리 (필요한 단계: 9)

- **나중에 읽기:** 링크만 보내면 요약해서 Notion "나중에 읽기"에 저장. 토요일 09:47 안 읽은 목록
- **서재:** PDF나 긴 텍스트를 올리면 저장해 두고, 질문하면 관련 쪽만 찾아 쪽 번호·인용과 함께 답해요 (`!docs`, `!docdel 번호`)
- **독서:** "○○ 읽기 시작했어", "다 읽었어" → 책 정보를 찾아 Notion "독서"에 기록

### 개발 (필요한 단계: 2, 메모는 9)

- "my-app 어제 뭐 바꿨지?", "이슈 만들어줘", "개발 일지 돌려줘"
- `!project my-app` → 그 저장소 기준으로 대화하는 전용 스레드
- "지난주 커밋 각각 한 줄로 요약해서 배치로 돌려줘" → 반값 배치로 처리하고 끝나면 결과
- `!playtest` → GitHub Actions에서 AI가 웹 게임을 직접 해 보고 결과를 보고 (11단계)

### 생활 (장소·카톡은 10, 버스·특보는 12)

- "오늘 날씨", "서면 ○○국밥 어때?" → 카카오 장소 검색과 블로그·카페 후기를 확인해 장단점과 링크
- `!out` 또는 "지금 나가도 돼?" → 날씨·3시간 내 비·바람·파도·특보·즐겨찾는 정류소 버스
- "이거 카톡으로 나한테 보내줘" → 카카오톡 나와의 채팅
- "토요일 7시 서면 ○○ 약속 카드 만들어줘" → 지도·길찾기·카톡 공유 버튼이 있는 페이지 (11단계)
- "해운대, 사상, 동래에서 만나기 좋은 곳" → 대중교통 시간이 가장 고른 역과 근처 가게
- 구글 주소록 생일 당일 알림 (`!birthdays`), 유튜브 구독 새 영상 요약 (`!yt`) (7단계)

### 알림·브리핑·대시보드

- **알림 정리:** 출발 알림·리마인더·긴급 메일·특보는 언제든 바로, 나머지는 조용한 시간(23~07시)에 모아 뒀다가 아침·12:30·18:30에 한 번에 (`!queue`, `!flush`)
- **아침 브리핑 (07:47):** 날씨·미세먼지·오늘 일정·첫 출발 시각·할 일·교체 주기·만료 쿠폰·밤사이 알림·오늘 동선 지도
- **나의 한 주 (일 21:07):** 일정·할 일·지출·읽기·커밋·비용 숫자와 짧은 코멘트 (`!week`)
- **대시보드:** `!dash` → 일정·할 일·지출·쿠폰·비용을 보여주는 암호화된 개인 페이지 (11단계)

### 관리

- **비용 가드:** 월 예산의 80%·100%에서 알림, 넘으면 절약 모드 (`!budget`, `!usage`)
- **재발급 알림:** 매일 토큰 만료를 점검해 14·7·3·1·0일 전에 알림 (`!renewals`)
- **자기 개선:** 매주 사용 기록을 분석해 프롬프트·도구 설명·설정 수정안을 PR로 올려요. 자동 병합하지 않아요 (`!improve`). 공개 저장소에서 쓰면 PR 본문에 사용 분석이 공개되니 비공개 저장소에서 쓰는 걸 권해요
- **백업:** 매주 구글 드라이브로 백업, 복구 스크립트 포함 (`!backup`)
- **설정:** 디스코드에서 `!set 경로 값` → `!restart`. 기본값은 [config.yaml](config.yaml)에 주석과 함께 있어요
- **업데이트:** `!update` → 최신 코드를 받고 재시작

## 동작 방식

```
디스코드 메시지 (텍스트·사진·파일)
   │
   ▼
① 라우터 (Haiku) ─ 간단/복잡 분류
   │
   ├─ quick ─▶ ② 지휘자 Haiku + Opus 어드바이저 (턴당 1회)
   └─ deep  ─▶ ② 지휘자 Sonnet + Opus 어드바이저 (턴당 3회)
                  │  delegate(agent, task) — 여러 개 동시 호출
                  ▼
        ③ 전문 에이전트 (각자 자기 도구만 가짐)
           mail · schedule · dev · research · life
                  │
                  ▼  대량·비긴급 작업
        ④ Message Batches (50% 할인) → 끝나면 결과를 디스코드로

백그라운드 루프: 메일 감시 · 리마인더 · 출발 알림 · 브리핑 · 리포트 · 백업 · 재발급 점검 · 생존 신호
```

### 에이전트

| 에이전트 | 맡은 일 | 도구 |
| --- | --- | --- |
| 지휘자 | 요청을 나눠 전문 에이전트에게 맡기고 답을 정리 | delegate, 메모리, 리마인더, 지출, 서재, 기억 검색 등 공통 도구 |
| mail | 메일 검색·읽기·요약·답장 초안 | Gmail (IMAP 읽기 전용) |
| schedule | 일정 조회·추가, 할 일 | 구글 캘린더, 톡캘린더, Microsoft To Do |
| dev | 커밋·diff·이슈·워크플로, 개발 메모 | GitHub API, Notion |
| research | 웹 검색·페이지 읽기·계산, 드라이브 검색 | Claude 서버 도구(웹 검색·코드 실행), 다음 검색, 구글 드라이브 |
| life | 날씨·장소·후기·버스·특보·카톡 보내기 | Open-Meteo, 카카오, 다음 검색, 공공데이터포털 |

### 비용을 줄이는 설계

| 방법 | 내용 |
| --- | --- |
| 모델 나누기 | 분류·실행은 Haiku, 복잡한 일만 Sonnet, 계획·막힘 순간에만 Opus 어드바이저 |
| 프롬프트 캐싱 | 도구 정의와 시스템 프롬프트 고정부는 1시간, 대화는 5분 캐시 |
| 배치 | 커밋 여러 개 요약, 야간 메일 요약은 Message Batches로 반값 |
| 서재 쪽 검색 | PDF 전체가 아니라 질문과 관련된 쪽만 골라 보내요. 질문당 보통 수천~2만 토큰 |
| 모델 안 쓰는 기능 | 출발 알림, `!spend`, 결제 문자 금액 읽기, 리포트 집계는 코드로만 처리 |
| 같은 일 기억 | 결제 문자의 가맹점 분류처럼 한 번 정한 결과는 저장해 두고 다시 묻지 않아요 |

## 안전장치

- 디스코드 소유자 ID 한 명에게만 응답해요.
- 일정 추가, 이슈 생성, 워크플로 실행, 카톡 전송, Notion 쓰기 같은 바깥에 영향을 주는 일은 **[실행]/[취소] 버튼**을 누른 뒤에만 해요.
- Gmail은 읽기 전용이에요. 읽음 표시도 바꾸지 않고, 답장은 초안만 만들어요.
- 비밀값은 VM의 `.env`·`data/`(Git 제외), GitHub Secrets, 폰 앱 안에만 있어요. 백업에도 들어가지 않아요.
- 자기 개선 PR은 고칠 수 있는 파일이 정해져 있고, 자동으로 병합하지 않아요.
- 결제 문자 전달 앱은 메시지 앱 알림 중 카드 결제 문자만 내보내고, 비서는 그 글을 지출 기록에만 써요.

## API 키와 사용량 유의 사항

Claude API 비용은 **내 Anthropic 계정으로 청구돼요.** 설치 전에 아래를 꼭 읽어 주세요.

- **비서의 예산은 추정치예요.** 월 예산·80% 알림·절약 모드는 비서가 기록한 토큰 수에 가격표를 곱해 계산한 값이라 실제 청구액과 다를 수 있어요. 실제 금액은 Anthropic Console의 사용량·결제 화면에서 확인해요.
- **Anthropic 쪽 한도도 걸어 두세요.** Console에서 비서 전용 워크스페이스를 만들어 월 사용 한도를 정하고, 그 워크스페이스의 키를 쓰는 걸 권해요. 비서의 예산이 실패해도 Anthropic 쪽에서 한 번 더 막아 줘요.
- **키는 비서 전용으로 하나 만들어요.** 다른 프로그램과 같은 키를 쓰면 비서 계산에 그 비용이 안 잡히고, 새어 나갔을 때 어느 쪽인지 알기 어려워요.
- **비서 계산에 들어가지 않는 비용이 있어요.** GitHub Actions에서 도는 플레이테스트(저장소 Secrets의 키 사용)와, 같은 키를 쓰는 다른 프로그램의 사용량이에요.
- **비용이 크게 드는 것:** 깊은 모드와 Opus 어드바이저, 웹 검색(1회 약 0.01달러), 긴 PDF에 대한 질문, 플레이테스트(1회 대략 턴 수 × 3천 토큰, Sonnet), 사진 여러 장 분석.
- **절약 모드도 0원은 아니에요.** 깊은 모드·어드바이저·플레이테스트·자기 개선은 멈추지만, 일반 대화와 메일 중요도 판단은 계속 API를 써요. 완전히 멈추려면 비서를 끄거나(`sudo systemctl stop ai-assistant`) Console에서 키를 비활성화해요.
- **그만 쓸 때는 연결도 정리해요.** 카드사 문자 알림은 해지하지 않으면 월 요금이 계속 나가요. 서비스별 해지 방법은 [설치 가이드의 그만 쓰기](docs/setup-guide.md#그만-쓰기-잠시-멈추기와-완전히-정리하기)에 있어요.
- **가격이 바뀌면 추정도 틀어져요.** 모델 가격은 `assistant/costs.py`에 적혀 있고, Anthropic 가격표가 바뀌면 `budget.prices` 설정으로 고쳐야 해요.
- **키를 노출하지 마세요.** 채팅, 스크린샷, 이슈, 저장소에 올리지 않아요. 노출됐다면 Console에서 그 키를 바로 지우고 새로 만들어요. 남이 쓴 요금도 내 계정으로 청구돼요.
- **새 계정은 요청 한도가 낮아요.** 짧은 시간에 요청이 많으면 오류(429)가 날 수 있어요. 사용 기록이 쌓이면 한도가 올라가요.

## 면책 고지

[MIT 라이선스](LICENSE)에 따라 있는 그대로 제공돼요. 설치와 사용으로 생기는 요금이나 손해에 대한 책임은 사용자에게 있어요. 비용과 안전을 위한 장치는 위의 [안전장치](#안전장치)와 [API 키와 사용량 유의 사항](#api-키와-사용량-유의-사항)을 참고해 주세요. 지출 기록과 리포트는 참고용이고, 실제 카드 명세서나 은행 거래 내역을 대신하지 않아요.

## 개발

```
assistant/
  bot.py          시작점. 디스코드 연결, 명령, 버튼, 백그라운드 루프
  agents.py       라우터·지휘자·전문 에이전트 정의와 대화 흐름
  tools/          에이전트 도구 (mail, google, personal, dev, life, library)
  store.py        SQLite 저장소
  settings.py     config.yaml + config.local.yaml 합치기, !set
  costs.py        비용 계산, 예산, 절약 모드
  ...             기능별 모듈 (mailwatch, commute, expenses, paysms, briefing 등)
deploy/           VM 설치 스크립트, Docker 진입 스크립트, 구글·MS·카카오 로그인 스크립트, 백업 복구
Dockerfile        Docker 설치용 (docker-compose.yml과 함께)
site/             GitHub Pages로 게시되는 웹 카드·대시보드
android/          결제 문자 전달 앱 (Java, Actions가 APK 빌드)
playtest/         AI 플레이테스터 (Actions에서 실행)
docs/             설치 가이드, 사용법
tests/            오프라인 테스트 (실제 API 없이 가짜 클라이언트로 전체 흐름 검증)
config.yaml       모든 설정의 기본값과 설명
```

```bash
python -m pytest -q tests/
```

코드를 고치면 GitHub Actions가 테스트를 돌리고, VM에서는 디스코드 `!update`로 받아 재시작해요. 사용법 문서에 적은 `!명령`이 실제로 있는지도 테스트가 확인하니, 명령을 바꾸면 [docs/usage.md](docs/usage.md)도 같이 고쳐 주세요.
